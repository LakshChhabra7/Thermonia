# Thermonia 

Thermonia is a model which is used to predict to and build shelters that can protect people from situations such as Heat waves, Coldness, Floods, Earthquacks, etcetera. 
Thermal comfort inside a shelter depends heavily on local climatic conditions — temperature range, humidity, solar radiation, wind pattern and precipitation — and on the materials, orientation and geometry used in construction.
Thermonia uses Multiple Regression on a collection of data of harsh climate behaviors (like in Ladakh, Rajasthan, Uttrakhand and many other places) to predict things that will be helpful for us to build shelters
